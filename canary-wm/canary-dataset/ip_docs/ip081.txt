Telegraphy and Morse Code

The electric telegraph separated communication from transport for the first time. Several systems competed in the 1830s and 1840s, among them the five-needle instrument of Cooke and Wheatstone in Britain, which pointed to letters on a diamond-shaped board and required six wires. The American system developed by Samuel Morse and Alfred Vail worked on a single wire and a simple sounder, and its economy decided the outcome.

The code assigns each character a sequence of short and long marks, with the shortest sequences given to the commonest letters. Vail is generally credited with setting the assignments by counting the type in a printer's case in Morristown, which is why E is a single dot and T a single dash. The original American code contained internal spaces within some characters and was replaced for international use by the Continental or International Morse code standardised in the 1860s, which is the version still in use.

Timing is defined in units rather than absolute durations. A dash is three units, the gap between elements one, between letters three and between words seven, so that the code remains legible at any speed. Skilled operators read by sound as words rather than by counting elements, and could work at thirty words a minute or more.

Submarine cables extended the system across oceans from the 1850s. Morse remained the maritime distress standard until the Global Maritime Distress and Safety System replaced it in 1999, and it survives in aviation navigation aid identifiers and in amateur radio, where its narrow bandwidth still carries through poor conditions.
